ndm. capture

A small companion for your background download engine. Capture is off until you turn it on.

Find both values in NDM’s Media grabber → Set up the browser companion. The token cannot change settings or delete downloads.

Only use this for content you own or have permission to save. Enable it only while you want media captured. NDM’s website allowlist and media-type preferences apply. No cookies, page contents, or browsing history are sent. DRM is never bypassed.
